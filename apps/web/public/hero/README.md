# Landing hero assets

Static locale-aware sources for the public landing hero, served from `/hero/*`.
The UI renders one 1448 × 1086 image and no carousel controls.

| File | Dimensions | Embedded language | Use |
|------|------------|-------------------|-----|
| `hero-family_en.png` | 1448 × 1086 | English | English hero and fallback |
| `hero-family_fr.png` | 1448 × 1086 | French | French hero |
| `hero-family_ar.png` | 1448 × 1086 | Arabic | Arabic hero |

Spanish uses the text-free project-generated
`/landing/family-example-02-v2.png`, documented in `public/landing/README.md`,
so the Spanish page never exposes English embedded artwork.

## Provenance hold

The origin and license of the three legacy files above are unrecorded. Do not
describe their subjects as Kafil beneficiaries or treat the files as evidence
of consent. Final asset acceptance remains blocked until they are replaced by
cleared artwork or their provenance is confirmed.

Essential meaning is present in localized HTML outside the image. The manifest
uses a localized concise alt-text key for each static image.
