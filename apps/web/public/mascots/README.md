# Mascots — `public/mascots/`

Text-free decorative artwork shared by all locales. Served as
`/mascots/...` content assets (not branding assets).

## Files

All five files are transparent PNGs, 1122 × 1402, with no embedded text:

| File | Approved placement | Decorative or meaningful |
|------|--------------------|--------------------------|
| `mascot-heart-gift.png` | CTA banner (required) | decorative (`alt=""`; heading carries the message) |
| `mascot-grocery-basket.png` | goods-based support section (optional, at most one secondary use) | decorative |
| `mascot-idea.png` | how-it-works section (optional) | decorative |
| `mascot-thumbs-up.png` | trust strip (optional) | decorative |
| `mascot-waving.png` | contact/footer region (optional) | decorative |

Secondary use is limited to at most two additional sections, never multiple
mascots in one section, and never a repeat of the CTA mascot elsewhere.

## Provenance

Origin, license, and generation method for the five existing PNGs are
unrecorded. They are text-free transparent illustrations as inspected, with
shared 1122 × 1402 source dimensions. This is an explicit hold, not a
clearance: confirm source/license (or replace the files with Kafil-owned
artwork) before final acceptance; do not assume ownership from presence in
the repository. Final acceptance stays blocked on these five files until the
hold is cleared.

## Accessibility

The CTA mascot is decorative: rendered with `alt=""` and kept out of the
accessibility tree. If a secondary mascot is later judged meaningful rather
than decorative, add a concise alt key to all four raw locale dictionaries
before rendering it; do not reuse English alt text in another locale.
